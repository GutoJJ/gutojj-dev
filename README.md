# Portfólio Terminal

Portfolio pessoal em React + TypeScript com visual estilo terminal, inspirado em um shell Linux.

## Sobre
Este projeto apresenta:
- informações sobre o autor
- habilidades e experiência
- projetos
- links relevantes
- comandos interativos no terminal

## Como executar
1. Instale as dependências:
   npm install

2. Rode o projeto:
   npm run dev

3. Acesse no navegador:
   http://localhost:5173

## Comandos disponíveis
- `help`
- `neofetch`
- `about`
- `skills`
- `experience`
- `projects`
- `contact`
- `github`
- `linkedin`
- `goold`
- `cv`
